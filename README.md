# 🏛️ 스파르타클럽 웹사이트 클론 코딩

> AX 1반 웹사이트 클론 코딩 스터디 결과물  
> 원본 페이지: [스파르타클럽](https://spartaclub.kr/)

## ✨ 프로젝트 소개

스파르타클럽 웹사이트의 주요 화면을 HTML, CSS, JavaScript로 클론 코딩한 학습 프로젝트입니다.

팀원별로 한 화면을 맡아 페이지의 레이아웃, 색상, 이미지, 메뉴와 버튼 등의 UI를 구현했습니다. 각 결과물은 독립적으로 실행할 수 있습니다.

> 이 저장소는 웹 퍼블리싱 학습을 위한 비공식 결과물이며, 스파르타클럽과 직접적인 관련이 없습니다. 상업적 용도로 사용하지 않습니다.

## ▶️ 실행 방법

별도의 설치 과정은 필요하지 않습니다.

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/aiagentohms/mock_up_team3.git
   ```

2. 원하는 화면의 폴더로 이동합니다.

3. 해당 HTML 파일을 브라우저에서 엽니다.

예시:

```bash
open "_2_이명지_전체강의/mock-page/all_lecture.html"
```

또는 VS Code의 **Live Server** 확장 프로그램으로 실행하면 더 편리하게 확인할 수 있습니다.
